# Проект “Виселица”
> Задача - реализовать игру “виселица” на Java. Интерфейс - консольный. Описание правил игры на [Википедии](https://ru.wikipedia.org/wiki/%D0%92%D0%B8%D1%81%D0%B5%D0%BB%D0%B8%D1%86%D0%B0_%28%D0%B8%D0%B3%D1%80%D0%B0%29).

#### @therenowhale
Мне было лень реализовывать полностью со всеми условиями, а-ля здоровье или рандомизация загаданного слова, поэтому вы сможете сделать это самостоятельно. Моя реализация охватывает лишь базовый функционал

## Требования

- Java 25 или новее.
- Терминал, открытый в папке проекта.

Проверить установленную версию Java:

```bash
java --version
```

## Запуск

Самый простой способ — запустить исходный файл напрямую:

```bash
java src/Main.java
```

После сообщения `Enter char:` вводи по одной букве и нажимай Enter.

Также можно сначала скомпилировать проект, а затем запустить его:

```bash
javac src/Main.java
java -cp src Main
```

После такой компиляции рядом с исходником появится `src/Main.class`. Это сгенерированный файл — его не нужно добавлять в Git.

## Что сейчас умеет игра

- Загадывает слово `Hangman`.
- Показывает закрытые буквы символами `_`.
- Открывает буквы после корректного ввода.
- Завершает игру после угадывания слова.
